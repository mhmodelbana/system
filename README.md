# نظام إدارة سوبر ماركت بنا

نظام متكامل لإدارة مخزون ومبيعات سوبر ماركت بنا باستخدام LocalStorage، يدعم اللغة العربية ويعمل بدون خادم (Serverless).

## المميزات الرئيسية

### 1. نقطة البيع (POS)
- بيع سريع بالباركود
- دعم قارئ الباركود
- إدارة سلة المشتريات
- حساب الضريبة تلقائياً
- طباعة الإيصالات
- دعم طرق دفع متعددة (نقدي، بطاقة، تحويل)

### 2. إدارة المنتجات
- إضافة وتعديل وحذف المنتجات
- إدارة الباركود
- تصنيف المنتجات
- تحديد أسعار البيع والتكلفة
- إدارة المخزون لكل منتج
- طباعة باركود المنتجات
- تصدير المنتجات إلى CSV

### 3. إدارة المخزون
- متابعة المخزون لحظية
- تنبيهات نقص المخزون
- جرد المخزون
- تسجيل حركات المخزون (إدخال/إخراج)
- تقرير المخزون الشامل

### 4. إدارة المستخدمين والصلاحيات
- إضافة مستخدمين جدد
- أدوار متعددة (مدير، كاشير، موظف)
- صلاحيات مفصلة لكل دور
- ربط المستخدمين بالفروع

### 5. التقارير
- تقرير المبيعات اليومية والشهرية
- تقرير الأرباح والخسائر
- المنتجات الأكثر مبيعاً
- العملاء الأكثر نشاطاً
- تقرير المخزون

### 6. إدارة الموردين
- إضافة وتعديل الموردين
- معلومات الاتصال
- تاريخ التعامل

### 7. إدارة المشتريات
- تسجيل مشتريات من الموردين
- تحديث المخزون تلقائياً
- تتبع تكلفة البضاعة

### 8. إدارة العملاء
- إضافة وتعديل العملاء
- برنامج الولاء والنقاط
- استبدال النقاط بمكافآت
- تتبع مشتريات العملاء

### 9. العروض والخصومات
- عروض عامة وعلى منتجات محددة
- خصومات بنسبة مئوية أو مبلغ ثابت
- تحديد فترة العرض
- تفعيل/إيقاف العروض

### 10. إدارة الفروع
- إضافة فروع متعددة
- تتبع أداء كل فرع
- ربط المنتجات والمستخدمين بالفروع

### 11. الإعدادات
- إعدادات الشركة
- نسبة الضريبة القابلة للتعديل
- تخصيص الإيصالات
- النسخ الاحتياطي السحابي
- استعادة البيانات

## التثبيت والتشغيل

1. قم بتحميل جميع الملفات
2. افتح ملف `index.html` في المتصفح
3. سجل الدخول باستخدام البيانات الافتراضية
4. ابدأ باستخدام النظام

## المتطلبات

- متصفح حديث (Chrome, Firefox, Edge, Safari)
- دعم JavaScript
- دعم LocalStorage

## النسخ الاحتياطي

### إنشاء نسخة احتياطية
1. اذهب إلى صفحة الإعدادات
2. اضغط على "تحميل نسخة احتياطية"
3. سيتم تحميل ملف JSON يحتوي على جميع البيانات

### استعادة النسخة الاحتياطية
1. اذهب إلى صفحة الإعدادات
2. اضغط على "استعادة نسخة احتياطية"
3. اختر ملف النسخة الاحتياطية
4. سيتم استعادة جميع البيانات

## المميزات التقنية

- **LocalStorage**: تخزين البيانات محلياً في المتصفح
- **بدون خادم**: يعمل بدون الحاجة لخادم
- **سريع**: أداء عالي وسريع
- **آمن**: البيانات مخزنة محلياً على جهازك
- **متجاوب**: يعمل على جميع الأجهزة (كمبيوتر، تابلت، موبايل)
